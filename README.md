# ChessAuto

> [!IMPORTANT]
> **IT IS HIGHLY RECOMMENDED TO USE A FINE-TUNED AI MODEL (LLM) BEFORE RUNNING THIS PROGRAM.**
> Using a standard (vanilla) LLM that has not been specifically trained for chess may result in poor move accuracy or sub-optimal decision making.

ChessAuto is an intelligent chess bot automation program that operates locally using a high-speed *Logical State Tracking* system integrated with local AI models via Ollama. This program is designed to detect piece movements in real-time through pixel sensors and autonomously execute the best moves generated by the LLM.

## Key Features

1. **Pure Logical Tracking (0ms Delay Sensor)**
   Uses a highly efficient and instantaneous BGR-based pixel movement detection algorithm (`cv2.absdiff`). This sensor can detect enemy moves immediately without heavily taxing the CPU, and is immune to visual screen effects such as square highlights.

2. **Local AI Integration (Ollama)**
   Supports local Large Language Models (LLMs) running through Ollama. The bot sends standard FEN strings to the AI to request the best next move.

3. **Automated Tactical Injection**
   The program uses the `python-chess` library to calculate which pieces are currently under attack (threats) and which enemy pieces can be captured (opportunities). This tactical information is automatically injected into the main prompt so the AI can make precise strategic decisions.

4. **Autonomous Physical Execution**
   The system interfaces with `pyautogui` to automatically control the mouse cursor, moving pieces on your screen or web browser autonomously.

5. **Visual Overlay (ESP)**
   Displays an 8x8 grid overlay and transparent piece markers on top of the game window, making it easy to monitor the bot's internal memory state.

## Prerequisites

Before running this program, ensure your system meets the following requirements:
- Python 3.x installed.
- Ollama installed and running in the background (localhost:11434).
- At least one AI model downloaded in Ollama (e.g., `llama3`, `qwen`, etc).

### Library Installation

Install all required Python dependencies by running the following command in your terminal:

```bash
pip install opencv-python pyautogui keyboard mss numpy chess
```

## How to Use

1. Open a chess game interface on your computer screen (e.g., via a web browser).
2. Ensure the chessboard is in its starting position (no pieces have moved yet).
3. Run the program by executing the batch script or directly running the Python file:
   ```bash
   python main.py
   ```
4. In the program terminal, a list of available Ollama models will be displayed. Enter the index number of the AI model you want to use.
5. The **Board Calibration** process will begin:
   - Hover your mouse cursor exactly over the **TOP-LEFT CORNER** of the chessboard, then press `Enter`.
   - Hover your mouse cursor exactly over the **BOTTOM-RIGHT CORNER** of the chessboard, then press `Enter`.
6. The bot will scan the brightness of the top and bottom rows to automatically determine whether you are playing as White or Black.
7. Press the **F10** key on your keyboard to start (ACTIVE) or pause (STANDBY) the bot.
8. When active, the bot will begin detecting movements and responding autonomously.

## Safety Mechanism

If the bot is active and you manually move the mouse cursor (more than 15 pixels), the system will detect this as a manual interruption and will automatically deactivate the bot to prevent cursor conflicts. Press **F10** again if you wish to reactivate it.
